\section{Introduction}
The \textsf{multicancel} package provides advanced, extendable parallel multi-line cancellations across math expressions, large operators, and plain text. 

Unlike traditional solutions, it prevents lines from slimming down dynamically when wrapping large content, maintains perfect math style scaling, and works natively across \textbf{pdf\LaTeX}, \textbf{\XeLaTeX}, and \textbf{Lua\LaTeX}.

\section{Usage}
Load the package in your preamble:
\begin{verbatim}
\usepackage{multicancel}
\end{verbatim}

\DescribeMacro{\multicancel}
The primary command is invoked as follows:
\begin{verbatim}
\multicancel[n]{content}
\end{verbatim}
Where |[n]| is an optional integer specifying the number of parallel cancel slashes (defaults to 1 if omitted), and |{content}| is the target text or equation.

\section{Examples}

\subsection{Standard and Infinite Scalability}
The macro handles any arbitrary number of lines without breaking:
\begin{itemize}
    \item Default (1 line): $\multicancel{x+y}$
    \item Double (2 lines): $\multicancel[2]{x+y}$
    \item Quadruple (4 lines): $\multicancel[4]{x+y}$
    \item Extreme (20 lines): $\multicancel[20]{\text{Nullified}}$
\end{itemize}

\subsection{Large Operators and Equations}
It scales perfectly without dropping script styles or breaking fractions:
\[
\multicancel[3]{\sum_{i=1}^{n} i} \quad \text{and} \quad \multicancel[4]{\int_{-\infty}^{\infty} e^{-x^2} \, dx} = \sqrt{\pi}
\]

\[
f(x) = \multicancel[2]{\frac{a_0 + \sum_{k=1}^{\infty} (a_k \cos kx + b_k \sin kx)}{2 \pi \cdot \sigma^2}}
\]

\section{Implementation Details}
The engine calculates bounding boxes dynamically via \textsf{TikZ} nodes, computing standard X-axis offsets symmetrically distributed around the absolute horizontal center line of the wrapped expression.
