\section{Introduction}
The \textsf{multicancel} package provides advanced, fully extendable, tallable, and color-compatible parallel multi-line cancellations. 

Unlike traditional math cancellation packages, it prevents slashes from flattening or slimming down when applied to large math symbols or long expressions. It works natively across \textbf{pdf\LaTeX}, \textbf{\XeLaTeX}, and \textbf{Lua\LaTeX} without causing layout alignment crashes.

\section{Interface Commands}
The package provides four main user-facing commands, all supporting custom line amounts via |[n]| and custom colors via an optional second argument:

\begin{itemize}
    \item |\multicancel[n][color]{content}| -- Forward parallel slashes (symmetrical distribution).
    \item |\multibcancel[n][color]{content}| -- Backward parallel slashes.
    \item |\multixcancel[n][color]{content}| -- Cross-cancellation (X-shaped slashes).
    \item |\multicancelto[n][color]{target}{content}| -- Parallel slashes ending with an arrow pointing to a target value.
\end{itemize}

\section{Examples and Testing}

\subsection{Basic Usage and Color Support}
\begin{itemize}
    \item Standard (3 slashes, red): $\multicancel[3][red]{x+y}$
    \item Backward (2 slashes, blue): $\multibcancel[2][blue]{A \cdot B}$
    \item Cross-Cancel (4 slashes, purple): $\multixcancel[4][purple]{M_n}$
    \item Cancel To Value (2 slashes, orange): $\multicancelto[2][orange]{0}{f(x) - f(x)}$
\end{itemize}

\subsection{Tallable and Extendable Math Verification}
The lines dynamically stretch across wide and high equations while maintaining a consistent visual slope:

\[
\multicancel[3][red]{\sum_{i=1}^{n} i} \quad \text{and} \quad \multibcancel[2][blue]{\int_{-\infty}^{\infty} e^{-x^2} \, dx}
\]

\[
f(x) = \multicancelto[4][teal]{\infty}{ \frac{a_0 + \sum_{k=1}^{\infty} (a_k \cos kx + b_k \sin kx)}{2 \pi \cdot \sigma^2} }
\]
